# Runtime world-render evidence

Captured from the generated Windows player in the opt-in coordinated smoke scenarios with Direct3D 11. These are actual camera renders of the running placeholder world. They **exclude the IMGUI interface** and therefore do not prove dialogue, map, storage or HUD presentation quality. Full-frame captures on this host returned black images and are deliberately not included.

- `inn-world.png`: occupied common-room blockout.
- `lab-world.png`: first lab visit geometry.
- `upstairs-world.png`: upper-floor guest rooms and landing.
- `kitchen-world.png`: Sylvie and the rear kitchen.
- `reedwater-world.png`: arrival in the Mud location.
- `three-v-six-world.png`: nine actual combatants over the Woodland encounter space. Additional units are an explicit test fixture, not authored content.

Reproduce with the commands in `../../PLAYTEST-OPENING.md`. See `../STATUS.md` for assertions and limitations. Render framing and placeholder aesthetics still need human acceptance in the user's normal Game window.
